# MMA3001 - Airfoil Self-Noise Prediction

## Project Overview
This project develops and evaluates machine learning regression models for predicting the scaled sound pressure level (SPL) generated by a NACA 0012 airfoil.

The model uses five predictor variables:
- Acoustic frequency
- Angle of attack
- Chord length
- Free-stream velocity
- Suction-side displacement thickness

The main engineering question is:
**How accurately can machine learning regression models predict airfoil sound pressure level from the other variables, and how well do these models generalise to a chord length not represented during training?**

## Dataset
The project uses the **Airfoil Self-Noise dataset**, containing **1,503 experimental observations** of NACA 0012 airfoil noise.

### Inputs
- Frequency (Hz)
- Angle of attack (degrees)
- Chord length (m)
- Free-stream velocity (m/s)
- Displacement thickness (m)

### Output
The regression target is: **Scaled sound pressure level (SPL), measured in dB.**

The dataset is stored locally in:
`data/airfoil_self_noise.dat`

The original dataset is publicly available from the UCI Machine Learning Repository:
**Airfoil Self-Noise Dataset**  
https://archive.ics.uci.edu/dataset/291/airfoil%2Bself-noise

## Computational Approach
The project compares several regression approaches of increasing complexity:

- Mean predictor baseline
- Multiple linear regression
- Polynomial regression
- Decision tree regression
- Support vector regression (SVR) with an RBF kernel

Model complexity is investigated through polynomial degree, decision tree depth, and SVR hyperparameters.
Predictor removal analysis is also performed to investigate the contribution of individual input variables to prediction performance, including sensitivity analysis using the selected nonlinear SVR model.

Models are evaluated using:
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- Coefficient of determination ($R^2$)
- Training and validation error
- Computational time
- Peak memory usage

Computational performance is further investigated using repeated timing measurements, model structural measures, and profiling of the selected SVR model.

## Validation Strategy
A central objective of the project is to evaluate whether the models can generalise to an airfoil chord length that was not represented during training.
The **0.1524 m chord length** is reserved as an untouched final test set. All observations associated with this chord are excluded from model development, model selection, and hyperparameter tuning.

The remaining five chord lengths are used for model development using **leave one chord out (LOCO) validation**. During each validation fold, one complete chord length is withheld and the model is trained using the remaining chords.

The project also compares:
- Random K fold validation
- Experimental condition grouped validation
- Leave one chord out validation

This comparison investigates how the independence of the validation data affects the estimated prediction error.
The final test chord is evaluated only after model development and selection are complete.

## Limitations
The models are developed from measurements for the **NACA 0012 airfoil** and the operating conditions represented in the supplied dataset.
The dataset contains only six discrete chord lengths and four free stream velocities. Model performance therefore demonstrates prediction within this experimental domain and should not be interpreted as evidence of generalisation to different airfoil geometries or operating conditions outside the measured range.

The final test set contains only one previously unseen chord length. Although this provides an untouched assessment of interpolation to that chord, performance on a single test chord should not be interpreted as representative of all possible unseen chord lengths.

LOCO validation performance is used during model and parameter selection. Consequently, the LOCO results represent development stage validation performance rather than a completely independent final performance estimate.

Prediction inputs are checked against the experimental range to prevent unsupported extrapolation.
